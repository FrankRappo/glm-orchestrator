ИНТЕРАКТИВНЫЙ GLM В WSL
=======================

Полноэкранный интерфейс, как у Codex:

    cd /work/my-project
    glm

Из любого каталога:

    glm tui --cwd /work/my-project

Команда /usr/local/bin/glm указывает на /work/glm/bin/glm. Без аргументов
диспетчер запускает bin/glm-tui; подкоманда tui делает то же самое. Нужен
интерактивный терминал. Для выхода используйте команду выхода в TUI или Ctrl+C.

Установленный ZCode CLI 0.16.9 не содержит пакет @zcode/tui. Поэтому
bin/glm-tui запускает собранный CLI из /work/zcode-official-source через
standalone Node. Проверено в WSL: TUI открылся, показал GLM-5.3 и ответил на
запрос. Путь к исходникам и сборка CLI должны существовать.
Официальная версия Node для исходников — 24.14.0. Отдельный standalone Node
установлен в `/opt/node-v24.14.0-linux-x64/bin/node`, и `glm tui` выбирает его
автоматически. Системный `/usr/bin/node` 22.23.1 оставлен как fallback. Для
ручного переопределения используйте `GLM_TUI_NODE=/путь/к/node`.

Текстовый чат через headless GLM остаётся доступен:

    glm chat --project /work/my-project
    glm chat --project /work/my-project --continue
    glm chat --project /work/my-project --resume sess_...

В текстовом чате после You> печатайте запрос и нажимайте Enter; /exit
завершает диалог. Контекст сохраняется через session ID. По умолчанию
выбран режим plan без Bash, Edit и Write. Для изменения файлов в текстовом
чате нужно явно указать --mode yolo:

    glm chat --project /work/my-project --mode yolo

Этот режим может выполнять команды и менять файлы без подтверждений.

Штатные команды установленного CLI по-прежнему проходят через glm-linux:

    glm --version
    glm doctor --json --no-color
    glm --prompt 'Ответь кратко: OK'

Для проверки авторизации и квот:

    /work/glm/bin/orchestrate doctor --live
    /work/glm/bin/orchestrate limits

Если команда glm не находится, проверьте ссылку:

    ls -l /usr/local/bin/glm

Она должна указывать на /work/glm/bin/glm. При отсутствии собранного TUI
bin/glm-tui сообщает путь к недостающему файлу; используйте glm chat до
сборки. При запуске от root обёртка запускает TUI под обычным пользователем
WSL, чтобы использовать его авторизацию. Этот пользователь должен иметь
доступ к каталогу проекта.
